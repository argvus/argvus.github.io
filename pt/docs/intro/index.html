Introdução

O Gnarus é um ambiente de desktop completo e pronto para uso, focado em Hyprland, empacotado para Arch Linux.

Ele não é apenas uma configuração pessoal: o projeto reúne um ambiente Wayland rico e integrado com uma barra Waybar no topo, lançadores Rofi e Wofi, uma sidebar de informações do sistema construída com Quickshell/QML e um gerenciador de armazenamento removível em Rust para o Waybar. Oito famílias de tema — dark, dark silver, light e slate (além das variantes float) — unificam GTK, terminal, rofi, dunst, waybar e o próprio Hyprland, todas guiadas por um sistema compartilhado de cores de destaque.

O projeto está em desenvolvimento. Os pacotes são publicados no branch gh-pages pelo workflow Publish Arch Package Repository.
