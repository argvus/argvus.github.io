Sobre

Por que ARGVUS?

ARGVArgument Vector
+
USUser System
ARGVUS

ARGVUS nasceu de uma ideia simples: um desktop não deveria exigir que o usuário interrompesse seu fluxo para procurar controles, navegar por menus ou depender constantemente do mouse. A proposta é construir um ambiente onde o teclado seja uma das principais formas de interação com o sistema — permitindo que ações, aplicações e ferramentas sejam acessadas por atalhos e comandos de maneira rápida e previsível.

O nome representa essa ideia. ARGV, de argument vector, remete ao mundo dos desenvolvedores e à forma como argumentos são utilizados para controlar programas. US, de User System, representa o objetivo de transformar essa filosofia em um ambiente de desktop centrado no usuário.

Componentes

Feito com software que você já conhece

O ARGVUS integra um ecossistema completo de ferramentas Wayland, todas pré-configuradas e com temas unificados.

Hyprland

Hyprland

Compositor Wayland que dá vida ao ARGVUS: tiling, workspaces, animações suaves e atalhos completos.

Waybar

Waybar

Barra de status com módulos de sistema, mídia, rede, armazenamento e atalhos.

Quickshell

Quickshell

Sidebar de informações em QML com clima, rede, calendário, brilho, volume e notificações.

Rofi

Rofi

Lançador de aplicativos, switcher de janelas e menus — tudo com temas unificados.

superfile

superfile

Gerenciador de arquivos em TUI, rápido e totalmente configurável, com atalhos dedicados.

btop

btop

Monitor do sistema com CPU, memória, rede e processos em tempo real.

hyprlock

hyprlock

Bloqueador de tela integrado ao ecossistema Hyprland com tema sincronizado.

argvus-storage

argvus-storage

Módulo de armazenamento removível escrito em Rust para a barra do Waybar.

Apps oficiais

Ferramentas nativas para o desktop

Além da configuração do ambiente, o ARGVUS inclui apps próprios para fluxos que precisam se integrar melhor à barra e aos painéis.

argvus-storage

argvus-storage

argvus-storage é o app de armazenamento removível do ARGVUS. Ele detecta dispositivos, expõe ações rápidas para montar, desmontar e ejetar unidades, e alimenta o módulo de armazenamento da Waybar com uma experiência consistente.

argvus-calendar

argvus-calendar

argvus-calendar é o calendário nativo usado pelo desktop. Ele oferece uma visualização rápida do mês, navegação simples e integração com eventos para consultar compromissos sem sair do fluxo do Wayland.

Instalação em um único pacote

O ARGVUS é publicado como pacote para Arch Linux, com repositório pacman e banco de pacotes hospedados no GitHub Pages do projeto packages.

  • Repositório pacman hospedado nas GitHub Pages em /packages/.
  • Índices navegáveis para /packages/arch/ e /packages/arch/x86_64/.
  • Instalação com sudo pacman -Syu argvus; dependências resolvidas a partir do mesmo repositório.
  • Configurações preservadas e reparadas automaticamente a cada login.
/bin/sh — instalação
# Importa a chave GPG
curl -fsSLo /tmp/argvus.gpg https://argvus.github.io/packages/arch/argvus.gpg
sudo pacman-key --add /tmp/argvus.gpg
ARGVUS_KEY="$(gpg --show-keys --with-colons /tmp/argvus.gpg | grep '^pub:' | head -n1 | cut -d: -f5)"
sudo pacman-key --lsign-key "$ARGVUS_KEY"

# Adiciona o repositório
curl -fsSL https://argvus.github.io/packages/arch/argvus.conf \
  | sudo tee /etc/pacman.d/argvus.conf
echo "Include = /etc/pacman.d/argvus.conf" \
  | sudo tee -a /etc/pacman.conf

# Instala
sudo pacman -Syu argvus
