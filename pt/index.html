Apps oficiais

Ferramentas nativas para o desktop

Além da configuração do ambiente, o ARGVUS inclui apps próprios para fluxos que precisam se integrar melhor à barra e aos painéis.

argvus-storage

argvus-storage

argvus-storage é o app de armazenamento removível do ARGVUS. Ele detecta dispositivos, expõe ações rápidas para montar, desmontar e ejetar unidades, e alimenta o módulo de armazenamento da Waybar com uma experiência consistente.

argvus-calendar

argvus-calendar

argvus-calendar é o calendário nativo usado pelo desktop. Ele oferece uma visualização rápida do mês, navegação simples e integração com eventos para consultar compromissos sem sair do fluxo do Wayland.

Instalação em um único pacote

O ARGVUS é publicado como pacote para Arch Linux, com repositório pacman e banco de pacotes hospedados no GitHub Pages do projeto packages.

  • Repositório pacman hospedado nas GitHub Pages em /packages/.
  • Índices navegáveis para /packages/arch/ e /packages/arch/x86_64/.
  • Instalação com sudo pacman -Syu argvus; dependências resolvidas a partir do mesmo repositório.
  • Configurações preservadas e reparadas automaticamente a cada login.
/bin/sh — instalação
# Importa a chave GPG
curl -fsSLo /tmp/argvus.gpg https://argvus.github.io/packages/arch/argvus.gpg
sudo pacman-key --add /tmp/argvus.gpg
ARGVUS_KEY="$(gpg --show-keys --with-colons /tmp/argvus.gpg | grep '^pub:' | head -n1 | cut -d: -f5)"
sudo pacman-key --lsign-key "$ARGVUS_KEY"

# Adiciona o repositório
curl -fsSL https://argvus.github.io/packages/arch/argvus.conf \
  | sudo tee /etc/pacman.d/argvus.conf
echo "Include = /etc/pacman.d/argvus.conf" \
  | sudo tee -a /etc/pacman.conf

# Instala
sudo pacman -Syu argvus
