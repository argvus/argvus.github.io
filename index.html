About

Why ARGVUS?

ARGVArgument Vector
+
USUser System
ARGVUS

ARGVUS was born from a simple idea: a desktop should not require the user to break their flow to find controls, navigate menus, or constantly depend on the mouse. The goal is to build an environment where the keyboard is a primary form of system interaction — allowing actions, applications and tools to be accessed through shortcuts and commands in a fast and predictable way.

The name represents this idea. ARGV, from argument vector, refers to the world of developers and how arguments are used to control programs. US, from User System, represents the goal of turning this philosophy into a user-centered desktop environment.

Official apps

Native tools for the desktop

Beyond environment configuration, ARGVUS includes first-party apps for workflows that need tighter integration with the bar and panels.

argvus-storage

argvus-storage

argvus-storage is the ARGVUS removable-storage app. It detects devices, exposes quick actions to mount, unmount and eject drives, and powers the Waybar storage module with a consistent experience.

argvus-calendar

argvus-calendar

argvus-calendar is the native calendar used by the desktop. It offers a quick month view, simple navigation and event integration for checking appointments without leaving the Wayland flow.

Arch Linux

Installed from a single package

ARGVUS is published as an Arch Linux package, with a pacman repository and package database hosted on the packages project page.

  • pacman repository hosted on GitHub Pages under /packages/.
  • Browsable indexes for /packages/arch/ and /packages/arch/x86_64/.
  • Installation with sudo pacman -Syu argvus; dependencies are resolved from the same repository.
  • Configs preserved and repaired automatically at every login.
/bin/sh — installation
# Import the GPG key
curl -fsSLo /tmp/argvus.gpg https://argvus.github.io/packages/arch/argvus.gpg
sudo pacman-key --add /tmp/argvus.gpg
ARGVUS_KEY="$(gpg --show-keys --with-colons /tmp/argvus.gpg | grep '^pub:' | head -n1 | cut -d: -f5)"
sudo pacman-key --lsign-key "$ARGVUS_KEY"

# Add the repository
curl -fsSL https://argvus.github.io/packages/arch/argvus.conf \
  | sudo tee /etc/pacman.d/argvus.conf
echo "Include = /etc/pacman.d/argvus.conf" \
  | sudo tee -a /etc/pacman.conf

# Install
sudo pacman -Syu argvus
