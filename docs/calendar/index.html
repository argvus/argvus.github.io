Calendar

argvus-calendar is the native ARGVUS calendar popup for Wayland/Hyprland, written in Rust with Relm4 and GTK4 and positioned with gtk4-layer-shell. It opens from the Waybar date module and provides a compact month view, agenda, event editor and reminders.

Opening

Section titled “Opening”

Click the date in the Waybar top bar. The module is configured as clock#date with "on-click" bound to the ARGVUS taskbar calendar action, which runs:

The popup is a single-instance layer-shell surface: it stays running after hiding, so toggle, show and hide go through a UNIX socket IPC at $XDG_CACHE_HOME/argvus-calendar/argvus-calendar.sock. It closes when you click anywhere outside it, click the date again, press Escape, or when it loses focus.

The launcher converts Waybar surface-relative coordinates into absolute desktop coordinates by reading the stable waybar layer origin from hyprctl layers -j + jq, falling back to hyprctl cursorpos -j on older Waybar versions.

Commands

Section titled “Commands”

Global flags: --x PX / --y PX (paired, allow negatives, position honored before or after the subcommand).

Configuration

Section titled “Configuration”

Configuration is split into system defaults and optional user overrides. The system config lives in /etc/argvus-calendar/config.toml. To customize, copy it to $XDG_CONFIG_HOME/argvus-calendar/config.toml and edit there. The application uses built-in defaults when the file is missing.

Open it for editing with argvus-calendar config, which launches a terminal with sudo (terminal from $TERMINAL or the [terminal] setting, editor from $VISUAL/$EDITOR or the [editor] setting, default nano).

The language setting supports "auto" (default), which detects the system locale from LC_ALL/LC_MESSAGES/LANG. Portuguese locales (pt-*) resolve to Portuguese; everything else resolves to English. Explicit "en-US" or "pt-BR" always overrides auto-detection.

The gear button in the popup opens the same config file. The popup reloads the config on each restart; argvus-calendar reload refreshes the external CSS/theme on the running popup.

Events and reminders

Section titled “Events and reminders”

Events are stored in a SQLite database. Event reminders can be disabled or configured in hours and minutes before the start; all-day events can additionally repeat their notification at a chosen interval during the day. Events that ended before the current local day are permanently removed, and new events cannot be created on past dates.

The events section is controlled by the in-window toggle and persisted in $XDG_CACHE_HOME/argvus-calendar/events-enabled; it is not configured in config.toml.

ICS import and export

Section titled “ICS import and export”

ICS import and export are supported through argvus-calendar import and argvus-calendar export. The export command rejects clobbering config or theme paths.

CalDAV

Section titled “CalDAV”

CalDAV support is implemented as a maintained internal HTTP/XML client foundation using PROPFIND/REPORT/PUT/DELETE. Account management and full database reconciliation are planned for a future release. Secrets are managed through the Secret Service API (pure-Rust crypto).

Styling

Section titled “Styling”

Styling is external: /etc/argvus-calendar/style.css provides structure, /etc/argvus-calendar/theme.css provides the packaged default, /etc/argvus-calendar/themes/ contains the ARGVUS themes, and $XDG_CACHE_HOME/argvus-calendar/theme.css is the user-level active theme written by the ARGVUS theme switcher.

Supported ARGVUS themes: Dark Aether, Dark Aether Float, Dark Silver, Dark Silver Float, Dark Slate, Dark Slate Float, Dark Universe, Dark Universe Float, Light Veil and Light Veil Float. The popup follows the desktop theme family and reads the active theme from $XDG_CONFIG_HOME/argvus/.active-theme.

Package

Section titled “Package”

argvus-calendar is packaged from its own repository at argvus/argvus-calendar. The PKGBUILD lives at packaging/PKGBUILD. It installs /usr/bin/argvus-calendar, the defaults under /etc/argvus-calendar/ and the user systemd unit at /usr/lib/systemd/user/argvus-calendar.service.
