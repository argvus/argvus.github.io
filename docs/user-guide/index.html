User Guide

ARGVUS is a modular Hyprland and Wayland desktop environment for Arch Linux. Start with installation, then choose a feature from the user guide.

The desktop combines a Hyprland session, a Waybar taskbar, a Quickshell control panel, native applications and system providers. The architecture guide explains how those pieces work together.

Common entry points

Section titled “Common entry points”
  • Open the settings application with argvus --control-center.
  • Open the calendar with argvus --calendar.
  • Inspect the session with argvus sessionctl status.
  • Read the installed command list with argvus --help.
