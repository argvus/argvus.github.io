Installing themes

This content is for v0.1.0. Switch to the latest version for up-to-date documentation.

The official themes are published as Arch Linux packages. Each theme is its own package named argvus-theme-<THEME_NAME>.

Where to get themes

Section titled “Where to get themes”

The source of every official theme lives in the ARGVUS project organization:

  • Each theme is a repository named argvus-theme-<THEME_NAME> (for example argvus-theme-dracula), built as a package with the same name.

Theme packages depend on argvus-appearance. Install ARGVUS first, as described in Installation, so that the appearance component is present.

Install a single theme

Section titled “Install a single theme”

To install every official theme at once, install the argvus-themes metapackage:

It depends on all published argvus-theme-* packages. ARGVUS Dark and ARGVUS Light are already shipped by argvus-appearance.

Install one theme with its package name:

For example:

The package installs the theme manifest, /usr/share/argvus/themes/<theme-id>/theme.toml (its name, category, wallpaper and palette, with optional overrides/), and the theme’s wallpaper under /usr/share/backgrounds/argvus/. The files of every component are rendered from the palette when the theme is applied. It does not write into your home directory, and it does not change your current theme. Select it from the Control Center afterwards, see Official themes.

Check what is installed

Section titled “Check what is installed”

List the installed theme packages with:

Open the Control Center and go to Appearance → Themes → Official Themes to see the themes that are currently available in the selector. A theme that is installed but missing from that list is a packaging problem; see the troubleshooting section of the Themes guide.

Add a theme of your own

Section titled “Add a theme of your own”

A theme is a manifest, so a theme of your own needs no package. Create ~/.local/share/argvus/themes/<id>/theme.toml, where the directory name is the theme ID (lowercase letters, digits and single hyphens):

Only bg, fg and accent are required: every other colour has a default derived from them, and the manifest defines one only to change it. Check it, then apply it like any other theme:

argvus theme list shows your themes next to the official ones (an official theme with the same ID wins). Your themes appear in the theme menu (SUPER + Shift + T); the pre-login greeter cannot read your home directory, so it keeps the last official theme you applied while one of your themes is active.

The per-theme copies that older ARGVUS versions wrote under ~/.config/argvus/data/<app>/themes/ are no longer read. The first theme switch after the update moves them to ~/.config/argvus/data/backups/theme-copies-<time>/; to keep a file you edited, put it in a theme of your own under overrides/ and name it in the manifest’s [overrides] table.
