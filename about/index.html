What is ARGVUS?

ARGVUS is a modular desktop environment for Arch Linux, built on Wayland and Hyprland. It brings the session, taskbar, control panel, settings and system integrations together as one cohesive experience. Its components are distributed across packages that work together, while Rust commands and applications live in the main workspace. The project focuses on fast, predictable interaction, with the keyboard at the center of the workflow.

ARGVUS was born from a simple idea: a developer desktop should not require the user to break their flow to find controls, navigate menus, or constantly depend on the mouse. The goal is to build an environment where the keyboard is a primary form of system interaction — allowing actions, applications and tools to be accessed through shortcuts and commands in a fast and predictable way.

The name represents this idea. ARGV, from argument vector, refers to the world of developers and how arguments are used to control programs. US, from User System, represents the goal of turning this philosophy into a user-centered desktop environment.
